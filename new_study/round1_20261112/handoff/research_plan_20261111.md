# 中国成年人身体活动改善的健康与直接医疗经济影响研究：执行计划

版本：2026-11-11。阶段：研究协议与逐项数据准入。本文是新稿和新分析的工作清单，不包含未经运行的结果。依据本项目已整理的31表输入簿、逐项证据登记和计算前门槛表。各阶段按下文验收后推进；未核准项目留空，不以旧稿结果倒推参数。

## 一、问题、边界与固定决定

研究问题：假定中国原本身体活动不足的成年人达到每周至少600 MET-min，在2025—2050年可产生多少健康收益及直接医疗支出变化？这是人群反事实情景的潜在影响，不等同于某项政策已经实现的效果或净收益。

| 项目 | 本轮工作口径 | 验收或仍需处理 |
|---|---|---|
| 人群 | 中国20岁及以上，分年龄与性别 | 当前人口输入为20+；公开活动观测的最年轻组为18—29，须处理20—29边界。18+仅在暴露与人口均相容时扩展 |
| 观测与模型基线 | 2018年CCDRFS为暴露观测；2025年为模型起点 | 2025细龄暴露属派生值，需恢复从观测到模型起点的变换，不冒充2025实测 |
| 时段 | 2025—2050年（26个日历年） | 30年方案为2025—2054年，补齐末四年资料后列为扩展 |
| 暴露与反事实 | 总身体活动量每周<600与达标；原本不足者进入≥600，暂按进入600—3999类别匹配RR | 核验调查活动领域、MET定义、风险比较方向；RR类别平均效应不能声称为恰好600时的点效应 |
| 时间 | 工作配置：2025年即达到并维持目标 | 这是反事实累计年数的设定；逐年达成作结构敏感性，须在正式运行前冻结具体达成年份与形式 |
| 方法 | 比较风险情景，年龄×性别×病种×年计算PIF/PIF变化 | 长期患者年指年度患病人数差值累计，不称为同一批患者病程跟踪 |
| 主视角 | 健康结果与直接医疗费用 | 不估计政策实施费、ICER、NMB、CEAC、ROI、GDP等价产出和照护/生产率收益 |
| 扩展 | RAND全人群活动量+20%及组合情景 | 仅在活动量分布和剂量反应风险到位后启动；不由二分类不足率推导 |

## 二、预先规定要报告的结果

| 结果 | 年度明细 | 累计与分层 | 解释与限制 |
|---|---|---|---|
| 身体活动不足人数及其变化 | 各年对照和反事实的年龄、性别人数/率 | 起始、5年、10年、2050对照 | 情景是潜在达标人数，不能称实际政策覆盖人数 |
| 可避免新发 | 疾病新发数与反事实差 | 病种、年龄、性别；5/10年及全期累计 | 病例定义以GBD incidence及匹配的发病RR为准 |
| 可避免死亡 | 年度疾病别Deaths差值 | 分病种及总量；年度、5/10年、2050累计 | 需核对死亡所对应的RR和时间解释；不同结局不能机械沿用发病RR |
| DALY、YLL、YLD | 年度病种别差值 | 主文DALY与构成、年龄性别贡献、关键区间 | 核对DALY=YLL+YLD；缺失或不相容病种不得以0凑总数 |
| 长期患者年 | 各年GBD Prevalence人数之差，高血压模块另列 | 累计减少的患病患者年、分病种贡献 | 这是比较风险情景下患病人数差值的年累计，不是动态患者队列随访；不能将所有病种病例数当互斥人数相加 |
| 直接医疗支出 | 年度新发首年费用或患病患者年费用择一接入 | 可归属病种、期间与视角明确的累计总额、结构与区间 | 费用仅限有本土可比证据的结局；重叠病费去重；未获得费用不记0 |
| 不确定性与稳健性 | 相同draw_id传递暴露、RR、基线和费用 | 95%模拟区间、病种映射/达成时间/高龄聚合的结构敏感性 | 结构范围不得伪装成经验95%CI |

总卒中须先分别处理缺血性、脑内出血、蛛网膜下腔出血的风险依据，再汇总；若仅缺血性有可用RR，主报告仅给缺血性结果并明确范围。高血压与CVD的病种贡献可能重叠；抑郁症没有相应死亡/YLL时不补造。女性特异癌症仅用相容人群。报告的总体健康负担是疾病别负担加总，须检查共同病例和因果中介影响，不能解释成互不重复的患者人数。

## 三、与原研究的具体区别

| 项目 | 原稿 | 新研究执行口径 |
|---|---|---|
| 目标 | S0动态基线与S1—S7政策情景、政策CEA | 身体活动达标反事实的健康与直接医疗影响；重新撰写全文 |
| 情景输入 | 政策覆盖/成熟/滞后和实施费 | 不足者达标及明确的生效时间；政策投入表退出模型 |
| 结果 | DALY、死亡、发病、患者年和政策成本、ICER/NMB/CEAC等，另有经济扩展 | 保留经核验的健康指标，医疗费用边界重建；不报告政策净效益 |
| 数据 | 旧工作簿中的派生暴露、旧`exact` RR、GBD标准化表及费用代理 | 原值保留追溯；逐项源文件、定义、年龄/性别和置信区间核对后才准入 |
| 计算 | 对各预测GBD指标分别施加PIF和滞后；长期患者年为患病差值累计 | 可借鉴比较风险框架，但为新情景重做RR、患病/死亡适用性和不确定性；不将原稿数值当校准目标 |

## 四、逐阶段工作清单与交付门槛

### 第1阶段：协议锁定与输入来源盘点（本轮已启动，未完成）

- [x] 固定研究方向、主情景、主要健康结局和政策成本退出范围。
- [x] 确认现有人口与GBD输入主要按20+整理；暂用2025—2050。
- [x] 核对工作簿、15个RR组件登记及2018—2023年GBD来源匹配状态。
- [ ] 把主情景生效时间、对照不足率2025后路径和年度维持约定写入冻结配置；原稿+0.84%只能在来源、推导和外推范围核验后使用。
- [ ] 把2018观测到2025基线的每一步变换及年轻年龄边界形成可复算记录。

**交付**：协议v1、输入字段字典、来源—派生关系图、固定分析配置。**门槛**：同一人群、暴露、年龄和年份口径贯通；两种人口2025分母的约5006万差异得到解释并选唯一分母。

### 第2阶段：人口与暴露（G01、G02、G08）

- [ ] 核对WPP版本、年中/年末时点、20岁及以上人口、年龄推进和原基线人口差异；保持单岁源与五岁/70+汇总可追溯。
- [ ] 回查2018年全国CCDRFS活动率与抽样CI，明确总活动、GPAQ域及<600阈值；细龄率若无来源则采用可支持的粗年龄层或显式近似情景。
- [ ] 将2025不足率标记为模型推算值；停用旧四省`psa_precision_n`充当全国精度。

**交付**：年龄×性别×年份人口、暴露原值及变换表、误差记录。**门槛**：率在0—1内、年龄聚合与来源总计一致、原始/派生分层清楚。

### 第3阶段：病种映射、风险和GBD（G03—G06、G09）

- [ ] 按13病种及卒中亚型逐条核对RR来源、活动领域、<600对照、达标类别、风险度量、结局和年龄性别；OR/HR不自动作RR。
- [ ] Kyu资料优先检查IHD、缺血性卒中和T2D“600—3999对<600”候选；不得计算没有分布权重的全体≥600平均RR。
- [ ] 恢复未找回的GBD原导出四包`142807b4`、`5f1ccb48`、`c66ef291`、`c6f1d9b8`及其查询条件；逐值核对死亡、YLL/YLD/DALY、发病、患病的2018—2023年序列。
- [ ] 检查70+细龄与总体的求和和区间方法；无draw时不把区间端点相加当聚合95%UI。
- [ ] 对每个病种分别登记新发、死亡、DALY、患者年四类结局的风险参数准入；风险滞后以证据或预设结构敏感性处理。

**交付**：疾病×组件×结局准入矩阵、原下载哈希及逐行比对。**门槛**：至少每一入模结局同时有可核查的GBD来源、正确映射和相容风险证据；否则从相应主结果排除并列缺口。

### 第4阶段：确定性健康模型（G07按结构适用）

- [ ] 建独立Notebook与最小输入白名单，按年龄×性别×年计算对照与达标场景的PIF差；对病种各指标明确采用何种风险证据及时间关系。
- [ ] 汇总年度及5/10年和至2050年结果，患者年按年度患病人数差值累计；标明不同疾病人数不可作去重人数。
- [ ] 执行零改善=零效应、RR=1=零效应、效应方向、DALY=YLL+YLD、年龄/性别/病种守恒、异常死亡与患病比例的诊断。
- [ ] 与独立外部负担资料比较基线量级；旧稿结果仅列差异解释，不拿来拟合。

**交付**：确定性Notebook、逐病种明细和诊断报告。**门槛**：输入均已准入，关键恒等和边界检查通过；未运行旧政策CEA。

### 第5阶段：直接医疗费用（G11、G12）

- [ ] 确定费用视角（建议直接医疗资源支出，不把就诊者费用直接乘全部GBD患者）；每病种选择新发首年或持续患者年成本及观察期。
- [ ] 核对本土实证来源、治疗覆盖、地区代表性、并发症与交叉病费；明确T2D与心脑血管重复、癌症治疗过程、痴呆直接医疗与总社会成本区别。
- [ ] 恢复完整价格指数及必要汇率的原值、起止年和换算式；建议统一2025年人民币，但不将换算价称为2025实测价。

**交付**：可入模成本表、转换账、年度与累计医疗费用。**门槛**：每条费用能追溯原文、单位、期间、对应健康量和去重规则；未核准病种标记未估计。

### 第6阶段：联合不确定性与敏感性（G13、G14）

- [ ] 将调查CI、RR区间、GBD不确定性和费用经验范围各自登记来源及分布；健康—医疗费用共用draw_id。
- [ ] 分开报告参数不确定性与结构情景：目标生效时间、2025对照趋势、年龄边界、疾病映射、高龄聚合、费用边界。
- [ ] 核对PSA每个draw的缺失、方向和极值；不继承旧PSA抽样精度或用旧结果重构新联合分布。

**交付**：抽样登记、可复现运行配置、区间和敏感性图表。**门槛**：输入哈希、代码版本、随机种子及draw完整性记录齐全。

### 第7阶段：论文与复现封库

- [ ] 用同一正式运行产生正文、补充材料、表图和摘要；正文集中于研究问题、核心健康和医疗费用结果，技术细节放附录。
- [ ] 逐项核查病种、单位、年份、累计/年度、未贴现/贴现、货币价格年、区间和图表编号一致。
- [ ] 把使用限制、源文件citation、独立复现命令、输入清单与不可入模证据一起封存。

**交付**：新研究分析包和可投稿稿件。**门槛**：独立运行可复现全部主要结果；旧研究文件保留在单独归档，不覆盖。

## 五、本轮实际核验结果与下一动作

原资料核验脚本的40项文件和登记一致性检查已通过；这不表示科学参数准入。现有RR登记15组件均为HOLD；2018—2023年GBD候选表的目标死亡、DALY、患病数值尚无对应原导出直接匹配，IHD和缺血性卒中仅部分发病数可直接匹配。费用证据表8项均为HOLD。由此判定：**可开发模型和继续收集证据，当前不能发布13病种正式新结果。**

下一执行动作是把“2025基线形成链＋主情景与对照的逐年定义”做成可复算登记，随后优先核对IHD、缺血性卒中、T2D的RR和GBD原件。已有数据先用于接口与检查，不生成冒充正式研究结果的数值。
