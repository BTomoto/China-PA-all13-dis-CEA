## 使用边界

1. `身体活动水平`是旧2025派生值。`PA观测证据`才是新录入的已发表观测资料。2018的18—29岁组不能直接拆成20—24/25—29；表列人数也不能当调查精度分母。四省`psa_precision_n`停用。
2. `GBD恢复原始`保留2010—2023范围内已找回的GBD估计量原导出记录，不是个体病例原始记录。含细年龄和部分直接70+，不同粒度不能一起相加。`GBD疾病负担`、`GBD病例`是原标准化候选副本。无源记录仍待核验，70+分量区间端点相加不作为有效聚合UI。
3. `人口细年龄`是从固定版本WPP再分发文件重算的派生资料。与旧算法一致不等于已独立确认联合国原文件时点定义；历史人口原分母与全因生命表仍需核对。
4. RR证据的分类、领域与风险度量不同；OR/HR不自动当RR，分类RR不自动当全体≥600的RR。未把13病种整体批准为新主分析。
5. 中国已就诊患者费用、疗程费用和全年患者费用含义不同。治疗覆盖、观察期及并发症重复计量未解决前不直接连接GBD患者数。两个旧费用表含同一候选的重复登记，不能相加。未核准的费用保留空值，未当作零。

## 下一步与完成条件

以[16项缺口进度表](registers/data_gaps_status.csv)为任务清单。当前`model_ready=false`，科学缺口未关闭。本轮没有运行新旧模型或10,000次PSA。

- **先定研究协议**：人群18+/20+、观测基线与模型起始年、评价期、总活动/休闲活动、二分类/剂量情景及变化路径。WHO原目标为2030相对2010不足率下降15%，只是已核实的外部参考，尚未选作正式情景。
- **按协议筛选证据**：只让定义相容的RR与结局进入主分析。细年龄暴露不可得时考虑调整报告分层，而非插值冒充观测。
- **恢复缺件**：尚缺`142807b4`、`5f1ccb48`、`c66ef291`、`c6f1d9b8`四个GBD源ZIP及查询记录，补齐近年细龄与不确定性。完整文件名见`GBD源登记`。
- **收集结构所需参数**：若采用动态疾病模型，再补生命表、自然史和结局滞后；若采用比较风险负担情景，先界定可解释的结局，不为保留旧结果强行新增病程假设。
- **完成医疗费用**：先补本土直接医疗边界和费用期间，再决定治疗覆盖、并发症去重、价格调整和联合draw。痴呆6225美元直接医疗派生值仍需原文复核；总社会成本不替代医疗费用。
- **最后建立独立Notebook与白名单**：输入核准后再建新流程；健康与费用共用draw_id。旧结果不作校准目标。

执行`python new_study/scripts/audit_inputs.py`可复核工作簿原值保留、登记行数、GBD原包哈希和人口算法核对结果。它仅验证资料整理，不表示科学参数齐备。
