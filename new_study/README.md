### 已发现的具体问题

1. `身体活动水平`中的`psa_precision_n`是旧四省分层精度假设，`DATA_AND_LICENSES.md`已明确其不是全国样本量。新研究不得继续将其用于全国监测精度；也不能把推算比例乘以该n得到真实观察计数。
2. 2025年身体活动表的source只指向旧补充表，未提供完整2018到2025的数值转换记录。原始全国监测分层表和抽样精度证据须补齐。
3. 两个GBD表的`70+`备注写明按分量累加lower/upper。分量区间端点相加不是得到有效聚合95%UI的一般方法；应尽可能恢复高龄分层与合适的不确定性资料。表内有原ZIP名称，但本次默认分支未见这些ZIP或完整查询记录。
4. `二分类RR`对ICH/SAH的来源明确为IS风险用于共用PIF，不能据旧`exact`或`APPROVED_PRESET_MAIN`标签视作亚型证据。癌症及其他proxy同样需重核。
5. `run_d1_d10_stage.calculate_health`直接计算`projected_value * pif_effective`并用于多个measure。它没有提供疾病状态衔接，不能原样用来预测新发、患者年、死亡与费用。
6. 医疗费用含早年本土研究、跨国代理及人为上下界。价格换算后的值仍是换算估计，不是2025年的实测费用；缺失费用不设为零。
7. 现有`economic_satellite_uncertainty`由健康结果汇总量另行重构经济分布。新研究应通过同一draw传递健康与医疗费用变化，记录依赖假设。

## 下一步工作顺序和完成标准

1. **研究协议**：确定人群、基线/评价期、活动指标、对照、目标轨迹、病种准入、主要/次要结局和价格年。二分类不足率不能直接支持RAND“整体活动量提高20%”情景。WHO目标须核对原目标参考年，不能擅自替换为新基线年。
2. **数据与证据核验**：完成G01—G06登记及GBD完整性检查；原始/标准化/推算值分层保存，按来源记录可获得性和使用条件。
3. **健康模型**：用明确的疾病发生和存活关系衔接患者年、死亡、YLD/YLL；对自然史不足的病种限制范围或采用明确结构情景。增加对照复现、流量守恒、零效应、极限情景及竞争死亡检查。
4. **医疗经济模块**：在健康模型一致后按新发事件、首年或后续患者年连接相应费用，说明漏计与重叠边界。不报告扣除政策实施费的净值。
5. **不确定性**：建立参数与结构情景分开的登记，保留draw_id贯穿结果；费用依据不足时提供明确范围分析，不将其伪装为经验95%UI。
6. **重算与新稿**：记录输入哈希、代码提交、配置和种子；结果、图表、摘要和Highlights由同一新运行生成。旧稿数字不作约束或拟合目标。

建议实施时在新研究独立分支逐步开发，已有可运行的旧代码留在快照中。当前未改变数据库名称及sheet名称；待新协议明确后再创建最小输入白名单与新schema。
