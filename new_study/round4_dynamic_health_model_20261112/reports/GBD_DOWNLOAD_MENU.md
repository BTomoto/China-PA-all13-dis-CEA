# Manual GBD download when logged in

Open [GBD Results Tool](https://vizhub.healthdata.org/gbd-results/) and sign in. Use the **GBD 2023 Results** release. Select `China`, `All Population`, `Male` and `Female`, year `2023`, causes `Ischemic heart disease` and `Ischemic stroke`, ages `20–24` through `90–94` plus `95+`. Select measures `Prevalence`, `Deaths`, `YLD`, `YLL` (and `DALY` for reconciliation); metrics `Rate` and `Number`. Request/download full precision point, lower and upper. Save the original ZIP without renaming in this round's `raw/` directory and retain the citation and query confirmation or screenshot. Do not select `Both` in place of sex strata or a composite stroke cause. The old incidence ZIP is already verified and need not be downloaded again.

Separately obtain a 2025–2050 age × sex all-cause mortality series or formal life table from WPP/UN, China official tables, or GBD; record population denominator and age definitions. Obtain the standard remaining-life table used for YLL, separately from China all-cause mortality. If GBD menus omit a listed age or cause, record the actual menu; do not split aggregate ages by assumption. Source files must pass SHA256, query scope, row uniqueness, UI ordering and Rate/Number implied-population checks before calibration.

Current status: **not downloaded**. Existing recovered ZIPs for other measures end before 2023; their values are not admitted here. IHME's [Results Tool user guide](https://ghdx.healthdata.org/sites/default/files/ihme_query_tool/GBD_Results_Tool_User_Guide_2019.pdf) says sign-in is required for download.
