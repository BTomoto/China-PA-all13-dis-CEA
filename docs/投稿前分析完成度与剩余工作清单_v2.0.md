# 投稿前分析完成度与剩余工作清单 v2.0

## 判断

原先列为“投稿前必须补充”的分析已完成到可形成论文扩展结果的程度，但并非所有模块都已达到顶刊正文主结论的证据强度。当前最合理的分层是：原programme-only CEA与正式PSA继续作为主分析；四病种医疗费用、公共支付方、GDP等价收益与投资回报作为预设卫星分析；严格CGE和病种特异医保支付比例不应在没有新数据时补造。

## 不属于中国主研究的差距

无需补做194国比较、全球地图、WHO区域排名、收入组不平等和跨国贸易传播。这些不是中国政策CEA的必要组成。

## 推荐稿件措辞

- 使用“扩展直接医疗费用节约”，不要称“完整13病种全生命周期医疗节约”。
- 使用“公共支付方桥接结果”，不要称“病种特异医保净节约”。
- 使用“GDP等价生产率收益”或“生产率收益”，不要称“动态CGE估计的GDP增加”。
- 将5年、10年维持为主分析；2025—2050年仍列为长期结构敏感性。
