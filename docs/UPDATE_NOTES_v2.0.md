# v2.0 更新说明

更新日期：2026-08-04

## 更新定位

v2.0 是投稿前经济扩展版本。它在已封库的 v1.3 健康效果模型、v1.4 正式 10,000 次 PSA 汇总和 v1.5 论文式结果稿基础上增加独立卫星分析，不替换、不重算也不修改原主分析和正式 PSA 结果。

## 新增内容

- 新增 `src/run_prepublication_extensions_v2.py`，用于生成投稿前扩展结果。
- 新增 `notebooks/04_投稿前扩展分析_四病种_医疗费用_GDP.ipynb`，作为 v2.0 结果读取和本地获授权数据重算入口。
- 新增 `input/prepublication_extensions/`，保存四类投稿前扩展参数：Lancet 中国基准、RAND 中国 GDP 基准、宏观及支付方参数、2025 年人民币医疗费用参数。
- 新增 `results/prepublication_v2/`，包括四病种健康结果、扩展医疗费用节约、排重审计、Lancet 同口径比较、GDP 等价生产率收益、RAND 校准、投资回报和经济卫星不确定性分析。
- 新增两份方法和完成度 Markdown 文档，以及两份 v2.0 结果展示 DOCX。
- 更新根目录 `README.md` 和 `data/README.md`，补充 v2.0 范围、运行顺序、数据边界与解释限制。

## 主要方法扩展

1. 补充 2 型糖尿病、抑郁症、痴呆和高血压疾病特异健康结果。
2. 在原 D4 部分费用边界之外，增加“首年事件费用＋年度患者年费用”的扩展直接医疗节约，并进行显式排重审计。
3. 使用 2025 年国家医保局数据形成全国公共支付桥接比例；该参数不是病种特异支付比例。
4. 增加 Lancet 2020—2030 年中国同口径 PAF 卫星复核与差异分解。
5. 增加缺勤、带病出勤和避免死亡三通道的 GDP 等价生产率收益、RAND 中国情景校准、收益成本比和回收期分析。
6. 对新增经济卫星模块执行 10,000 次不确定性抽样；该抽样不是原联合 PSA 的重跑。

## 解释边界

- v2.0 不改变 programme-only CEA 主分析、正式 CEAC/CEAF/EVPI 或既有正式 PSA。
- 扩展直接医疗节约不是完整 13 病种医保净节约。
- 全国公共支付比例是桥接值，不应表述为病种特异支付参数。
- GDP 输出是机制核算和 RAND 校准的“GDP 等价生产率收益”，不是动态 CGE 或严格宏观 GDP 效应。
- Lancet 同口径结果对身体活动不足率口径敏感，应保留为重要结构敏感性。
